How to join

Grab a seat at the table

Joining takes less than a minute. Non-premium players can join too.

BEDROCK ultimatedonutsmp.bedrock.minekeep.gg

Java Edition

Join in 5 steps

  1. Open Minecraft: Java Edition

    Start the launcher and pick version 26.2. Older versions can join too.

    Minecraft: Java Edition
    Version: 26.2 (latest)
    PLAY

  2. Multiplayer → Add Server

    On the main menu click Multiplayer, then Add Server at the bottom.

    Play Multiplayer
    Join Server Direct Connect Add Server
    Edit Delete Refresh

  3. Enter the server address

    Give it any name you like, then paste this into Server Address and click Done:

    ultimatedonutsmp.minekeep.gg
    Edit Server Info
    Server Name
    UltimateDonutSMP
    Server Address
    ultimatedonutsmp.minekeep.gg
    Done

  4. Click Join Server

    Select UltimateDonutSMP in your server list and click Join Server. Welcome in!

    UltimateDonutSMP PVP and Explore. Will you join?
    PVP | Survival | AFK and more!
    Join Server Cancel

  5. Install Simple Voice Chat Optional

    Want to talk to nearby players? Install the Simple Voice Chat mod for your version (it runs on Fabric, Forge, NeoForge or Quilt). You'll get a voice chat prompt when you join.

    Proximity voice: ON
Bedrock Edition

Playing on phone, console or Windows Bedrock?

  1. Open Minecraft (Bedrock Edition) and tap Play.
  2. Go to the Servers tab, scroll down and tap Add Server.
  3. Enter any name, and use this as the Server Address:
    ultimatedonutsmp.bedrock.minekeep.gg
  4. Leave the port on 19132, tap Save, then join.

FAQ

Questions? Answers.

Which version do I need?

The server runs on Java Edition 26.2, but older versions can join too. Bedrock players can join with ultimatedonutsmp.bedrock.minekeep.gg.

Can non-premium players join?

Yes! Non-premium players can join too.

How do I use voice chat?

Install the Simple Voice Chat mod for your Minecraft version and join the server. You'll get a voice chat prompt when you join. Then just talk – players near you will hear you.

How do I report a hacker?

Type /reporthacker <user> <reason> in game. Staff will take a look.

Where do I get help?

Ask staff in game with /helpop, or ask in our Discord.
